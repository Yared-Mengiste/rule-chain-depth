The saved evidence agrees across several fields: `query_added_statements`

no call to the observed PeTTaChainer query handler, consistent with the service's
exact-fact lookup returning first. The source hashes recorded in the
[PLN manifest](../benchmark/20261007T111319Z-d88e08/pln_rag/manifest.json) matched
the inspected `core/service.py` and `core/reasoner.py` files when this note was
written.

Both question workers began from the same saved learning snapshot. The control's
false positive arose from a statement introduced within that question's own
